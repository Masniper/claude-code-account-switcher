# Windows: предварительная сборка

[← README](../../README.ru.md) · [English](../windows-quickstart.md)

Предварительная сборка CLI и **Claude Accounts**, приложения-менеджера, для Windows, из ветки `build/windows-preview` форка. Она не подписана и не проходила ревью в основном репозитории.

## Перед началом

- Claude Code должен быть установлен, а `claude --version` — работать в PowerShell. `claude-acc` запускает то, на что указывает `claude`. `claude-acc doctor` предупредит, если это псевдоним приложения Microsoft Store в `WindowsApps`, а не Claude Code.
- Интеграция, которую добавляет `install`, — это скрипт профиля PowerShell. Если политика выполнения не запускает скрипты профиля, `install` и `doctor` об этом скажут. Чтобы разрешить:

  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```

## Установка

Оба файла — из одной предварительной сборки. Они собраны вместе; используйте их вместе.

1. В PowerShell, в папке с ними, установите CLI:

   ```powershell
   .\claude-acc.exe install
   ```

   Нужен `claude-acc.exe` этой сборки, а не релиз 0.21.0. Интеграция с VS Code на Windows копирует установленный бинарник, и только в этой сборке есть режим, в котором работает эта копия. `install` оставляет существующий бинарник с тем же номером версии, поэтому, если там 0.21.0, сначала удалите `%USERPROFILE%\.claude-switch\bin\claude-acc.exe`.
2. Запустите `Claude Accounts_<version>_x64-setup.exe`. Windows SmartScreen предупредит о неподписанном установщике: выберите **More info**, затем **Run anyway**.

## Чем отличается от macOS

- **Open Claude, вход и Add account** открывают окно консоли со встроенным `claude-acc`. Если CLI завершится с ошибкой, окно ждёт нажатия клавиши, чтобы сообщение можно было прочитать. Скопируйте его, если сообщаете о проблеме.
- **Move to Trash** отправляет папку в Корзину. Если папка слишком велика для Корзины, Windows спросит, прежде чем удалить её насовсем; отмена оставляет её на месте.
- **VS Code** настраивается на `%USERPROFILE%\.claude-switch\bin\claude-vscode.exe` — копию `claude-acc.exe`.
- **Использование Claude Desktop**: ключ профиля расшифровывается через DPAPI для вашего пользователя, без запроса. Что Claude Desktop на Windows хранит токен именно так, на реальной установке ещё не проверено.
- **Общий рантайм Desktop** (`clone-runtime`) недоступен: в NTFS нет клонирования с копированием при записи, поэтому профиль скачивает свой рантайм.

## Если что-то не работает

Запустите `claude-acc doctor` и сохраните вывод вместе с сообщением, которое показало окно консоли.
